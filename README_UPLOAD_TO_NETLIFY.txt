THREEFOLD NETLIFY SITE PACKAGE

Upload this entire folder to Netlify, not only index.html.

Required structure:
- index.html
- images/

Important:
The HTML now references images from ./images/.
If you upload only index.html, the images will be broken.

Best Netlify upload method:
1. Keep this folder unzipped or unzip the provided package.
2. Drag the whole folder into Netlify deploys.
3. Make sure index.html and the images folder stay together.
